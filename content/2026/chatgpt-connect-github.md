在 ChatGPT 里面安装 GitHub 插件，并授予它相关仓库的权限。

完成授权之后，就可以直接在 ChatGPT 网页版的聊天里读取仓库、修改文件、提交代码，不需要单独切到 Codex。

目前这种方式不会消耗你的 Codex 额度，相当于可以直接在普通 ChatGPT 对话里持续写代码。
