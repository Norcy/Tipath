用 [网易 UU 远程](/Tipath/tips/2026/netease-uu-remote-ai-essential/) 控制 Mac，电脑上很好用，但手机上看完整桌面，字太小，操作也不顺手。

强烈推荐安装 **[Snug](https://github.com/zephyr4123/snug)**，开源免费。

它会给 Mac 创建一块适配手机比例的虚拟竖屏，让窗口铺满手机屏幕，还优化了移动端手势，比如单指滑动滚动页面、长按调出右键菜单。

**配合网易 UU，手机远程操作 Mac 的体验直接提升十层楼。**

下载：[Snug GitHub Releases](https://github.com/zephyr4123/snug/releases/latest)。
