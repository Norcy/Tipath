## 1. 先搞懂 NAT：路由器是怎么工作的？
家里的电脑通常使用内网 IP，例如 192.168.1.10，路由器有一个对外使用的公网 IP，例如 1.2.3.4。

假设电脑上的 Tailscale 要连接 Tailscale 服务器，整个过程是：
1. Tailscale 向系统申请使用一个本地端口，例如 7777。
2. Tailscale 从 192.168.1.10:7777 向外发送数据。
3. 数据经过路由器时，路由器通过 NAT 分配一个临时公网端口，例如 8888。
4. 路由器把来源地址转换成 1.2.3.4:8888，并记录这个端口对应 192.168.1.10:7777。
5. 外面的服务器收到数据后，看到的来源就是 1.2.3.4:8888。
6. 服务器回复时，路由器根据 NAT 记录，把数据转发回电脑的 7777 端口。

这里有两个不同的端口：
- 电脑本地端口 7777：软件向操作系统申请的
- 路由器公网端口 8888：路由器开放的临时随机端口

举个例子，NAT 就像小区门卫的收发快递机制
- 路由器：小区门卫
- 公网 IP：小区地址。
- 内网 IP：小区里的具体住户。
- 电脑本地端口：住户内部负责收件的窗口。
- 路由器临时公网端口：门卫为这次通信登记的收件编号。
- NAT 记录：门卫的收发登记簿。

电脑向外发送数据时，对外显示的是小区地址，而不是住户的内部地址。
外面的数据回来时，门卫根据登记簿，把数据转交给正确的住户和端口。

## 2. 临时公网端口安全吗？
路由器暴露了临时公网端口，不等于任何人都能连接。
因为路由器只允许目标 IP+端口的数据通过
日常上网时，路由器实际上就在不断建立这样的临时端口映射。

## 3. Tailscale 怎么让手机和家里电脑找到彼此？
假设手机在外面使用 5G，电脑在家里。双方都安装并运行 Tailscale。

### 第一步：电脑保持与 Tailscale 服务器联系
1. 电脑主动建立与 Tailscale 服务器的通信时，路由器会建立 NAT 记录。Tailscale 服务器也获得了路由器的公网 IP + 端口，如1.2.3.4:8888 
2. 随后 Tailscale 需要持续运行，保持与服务器的联系

### 第二步：手机上线
1. 手机上的 Tailscale 也连接服务器，使用 5G 时，运营商的 NAT 设备发挥着类似家里路由器的作用。此时 Tailscale 也获得手机当前用于对外通信的公网 IP + 端口，例如：5.6.7.8:9999。

### 第三步：服务器交换双方地址
手机上线后，服务器把：
- 手机的 5.6.7.8:9999 告诉电脑。
- 电脑的 1.2.3.4:8888 告诉手机。

电脑无法提前知道手机的地址，但因为电脑上的 Tailscale 一直运行，与服务器保持联系，所以手机上线后，电脑就能收到服务器传来的地址信息

## 4. NAT 穿透为什么能成功？
关键问题：电脑之前只和 Tailscale 的服务器通信，为什么路由器后来会允许手机的数据进入？

因为电脑接下来也会主动向手机发送数据。注意这是新的连接。与 Tailscale 服务器的连接是并列的关系

1. 电脑向手机的 5.6.7.8:9999 发送数据。
2. 电脑的路由器建立或更新 NAT 记录，允许符合条件的手机数据返回。
3. 如果手机那边还没建立对应记录，电脑发送的第一条数据可能被拦截。
4. 手机也主动向电脑的 1.2.3.4:8888 发送数据。
5. 手机那边的 NAT 也建立对应记录。
6. 双方继续尝试发送，当两边都允许数据通过时，就建立了直接连接。

这里并不要求谁先发送，也不要求第一条数据就成功到达。
双方各自主动向对方发送数据，让各自的 NAT 建立通信记录，然后继续尝试，直到能够双向通信。

这就是 NAT 穿透的基本原理。它不是绕过路由器，而是利用路由器本来就允许的主动向外通信机制。

## 5. 连接建立后，还需要经过 Tailscale 服务器吗？

正常直连情况下，实际数据不经过 Tailscale 服务器转发。

通信路径是：手机 → 互联网 → 家里路由器 → 家里电脑。

Tailscale 服务器负责帮助双方找到彼此、交换连接信息。
双方建立直接连接后，手机和电脑上的 Tailscale 软件负责后续通信。
电脑仍然可以与 Tailscale 服务器保持联系，但实际的手机与电脑通信不需要绕道服务器。

## 6. Tailscale 为什么安全？

主要有两层保护：

第一层：路由器 NAT。路由器根据临时 NAT 记录和过滤规则，限制哪些外部数据可以进入。

第二层：Tailscale。Tailscale 使用 WireGuard，可以简单理解为：对通信进行安全加密，并验证通信设备的身份。

即使别人知道你的公网 IP + 端口，也不代表能够访问你的电脑服务。
安全不是靠隐藏公网 IP，而是靠网络访问限制、身份验证和加密通信。

## 7. 把整个流程串起来

1. 家里电脑保持开机，Tailscale 软件持续运行，并与服务器保持联系。
2. Tailscale 在电脑上使用本地端口。
3. 路由器通过 NAT 建立临时公网端口映射。
4. 手机上线后，Tailscale 服务器帮助双方交换公网 IP + 端口。
5. 手机和电脑主动向对方发送数据，让各自的 NAT 建立对应记录。
6. 双方建立直接连接。
7. Tailscale 对通信进行加密和身份验证。
8. 之后手机直接通过互联网访问家里电脑上的服务，不需要经过 Tailscale 服务器转发实际数据。

一句话总结：Tailscale 先让双方通过服务器找到彼此，再利用 NAT 穿透建立直接连接，最后通过加密和身份验证，让手机安全地访问家里的电脑
