title: Codex CLI 在 iTerm2 中鼠标滚轮无法查看对话历史
date: 2026-10-08T15:08:00+08:00
tags:
  - Codex CLI
  - iTerm2
  - Terminal
summary: iTerm2 中开启 Enable Mouse Reporting，解决 Codex CLI 鼠标滚轮无法查看历史对话的问题。
---

**问题：** 鼠标滚轮向上滚动时，无法查看历史对话，反而会切换输入框中的历史命令。

**解决：** iTerm2 → Settings → Profiles → Terminal → 开启 **Enable Mouse Reporting**。
